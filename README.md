# 🍔 O Templo do Smash & Bar

Landing page responsiva e moderna desenvolvida para a hamburgueria artesanal **O Templo do Smash & Bar**. O projeto conta com design estilizado em CSS, navegação fluida, cardápio detalhado, ícones de redes sociais e efeitos visuais dinâmicos criados com JavaScript (`IntersectionObserver`).

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estrutura semântica da página.
* **CSS3:** Estilização avançada, variáveis, fontes personalizadas (`Cinzel`, `Cormorant Garamond`, `Roboto`) e design responsivo com `clamp()`.
* **JavaScript (ES6+):** Animações dinâmicas de revelação de seções no scroll utilizando `IntersectionObserver`.

---

## 🎨 Funcionalidades

* 📱 **Layout Responsivo:** Adaptado para diferentes tamanhos de tela (desktop, tablets e celulares).
* ⚡ **Animações de Scroll:** Elementos aparecem suavemente conforme o usuário navega pela página.
* 🍔 **Cardápio Interativo:** Seções organizadas com hambúrgueres artesanais, acompanhamentos, bebidas e sobremesas.
* 📍 **Informações Completas:** Seção "Sobre Nós", rodapé com dados de contato, endereço e links para redes sociais.
* 💬 **Ação Rápida:** Botão flutuante integrado para contato direto via WhatsApp.

---
